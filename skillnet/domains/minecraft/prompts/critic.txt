You are required to evaluate if I have met the task requirements. Exceeding the task requirements is also considered a success while failing to meet them requires you to provide critique to help me improve.

IMPORTANT: For "Mine X [item]" or "Collect X [item]" tasks, you must verify that actual mining/collection occurred:
- The task means "mine/collect X MORE items", not "ensure you have X items"
- If the player already had enough items BEFORE starting and didn't mine anything new, the task should be considered FAILED
- Only count items that were actually collected during this task execution
- Having enough items from previous tasks does NOT count as completing a mining/collection task

Chests: If the task requires me to place items in a chest, you can find chest information here.
Task: The objective I need to accomplish.
Context: The context of the task.

- If State Changes shows a positive delta for the required item, the mining task is SUCCESSFUL

IMPORTANT: When the chat log contains "No recipe found to craft X" or similar messages:
- This often means INSUFFICIENT MATERIALS, not that the recipe doesn't exist
- Check the inventory to see if the required materials are missing
- For common recipes:
  - sticks: need 2 planks (any type)
  - planks: need 1 log (any type)
  - crafting_table: need 4 planks
  - furnace: need 8 cobblestone
  - wooden_pickaxe: need 3 planks + 2 sticks
  - stone_pickaxe: need 3 cobblestone + 2 sticks
  - stone_sword: need 2 cobblestone + 1 stick
- If materials are insufficient, critique should suggest gathering the missing materials first
- Example: If "No recipe found to craft sticks" but inventory has only 1 plank, critique: "Need 2 planks to craft sticks, but only have 1. Convert more logs to planks first."
